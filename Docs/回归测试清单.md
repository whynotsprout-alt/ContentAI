# 回归测试清单（按场景映射）

## P0
1. 流式异常/中断路径
   - 场景：`execution_failed`、`execution_interrupted`、`execution_cancelled` 事件到达时，前端 runLifecycle 必须变更为对应状态并关闭流。
   - 覆盖：`backend/tests/test_api.py`、`frontend/tests/workbench-cross-session.spec.mjs`

2. 无 tenant/user 上下文
   - 场景：未携带 tenant/user 的鉴权上下文请求，接口返回非 2xx 且不落库。
   - 覆盖：`backend/tests/test_api.py`、`backend/tests/test_main.py`、`backend/tests/conftest.py`

3. 工具安全阈值
   - 场景：未注册工具/无超时配置不允许执行（或直接失败）。
   - 覆盖：`backend/tests/test_hotspots.py`、`backend/tests/test_search.py`

## P1
4. 事件兼容清理
   - 场景：SSE 流中仅出现 `token` 与 `tool` 两类事件类型。
   - 期望：前端不再订阅旧事件名。
   - 覆盖：`frontend/src/stores/workbench.ts`（静态检查）与 `frontend/tests/workbench-cross-session.spec.mjs`（E2E 风格事件桩）

5. 接口文档
   - 场景：`Docs/兼容性说明.md`、`Docs/审查结论.md`、`Docs/删除清单.md`、`Docs/README.md` 一致更新。
   - 覆盖：文档审查

## P2
6. 会话与记忆一致性
   - 场景：流式回复后 message 与 execution 状态一致。
   - 覆盖：`backend/tests/test_memory.py`、`backend/tests/test_memory_repository.py`

7. 清理后启动验证
   - 场景：已清理/待清理文件移除后应用启动与路由扫描仍正常。
   - 覆盖：`backend/tests/test_main.py`
