# 用户状态提示与上海时区设计

## 目标

保留 ContentAI 对话工作台现有的中文运行状态提示，仅移除状态栏后半段的候选数量、来源健康度和平台名称等辅助信息。所有用户可请求的当前时间固定为亚洲/上海时区。

## 范围

### 运行状态栏

- 保留现有的中文主状态文案，包括运行、排队、重连、等待确认、取消和失败提示。
- 删除状态栏中的候选数量、来源健康度和平台名称明细；状态栏只保留图标与主状态文案。
- 主状态文案仍可使用现有 SSE 进度标签，不改写当前中文提示。

### 错误提示

- 保持现有错误提示行为不变；本次不调整流式错误和其他页面错误文案。

### 时间

- `current_datetime` 不再接受可变时区参数，始终使用 `ZoneInfo("Asia/Shanghai")`。
- 返回值中的 `timezone` 固定为 `Asia/Shanghai`，日期和时间均由该时区的当前时间生成。
- 事件与数据库的存储时间维持现有语义；本次只限制面向用户的当前时间能力，避免改变审计与排序行为。

## 实现边界

- 前端继续使用现有主状态文案逻辑；后端事件中的候选和来源字段仍可供内部使用，但不进入状态栏界面。
- 不新增工作流阶段或持久化状态字段，保持现有“对话式流程”的产品约束。
- 不修改现有未提交的发布、打包和运维文档改动。

## 测试与验收

1. 前端源码契约测试覆盖：状态栏不再渲染候选数量、来源健康度或平台名称明细，且保留既有主状态文案逻辑。
2. 后端单元测试覆盖：当前时间工具返回 `Asia/Shanghai`，并与该时区当前日期一致。
3. 既有前端和相关后端测试继续通过。
