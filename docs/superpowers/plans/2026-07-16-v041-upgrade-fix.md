# ContentAI V0.4.1 Upgrade Fix Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Repair the Ubuntu upgrade-script permission failure and publish immutable V0.4.1 source and deployment artifacts without altering V0.4.

**Architecture:** Make `upgrade.sh` invoke sibling scripts with Bash rather than relying on executable bits preserved by Git/tar. Rebuild the existing production package as `0.4.1`, then publish a new annotated tag and GitHub Release.

**Tech Stack:** Bash, PowerShell, Docker Compose v2, pytest, npm, uv, Git, GitHub CLI.

## Global Constraints

- Preserve the existing `V0.4` tag, Release and asset unchanged.
- Use `0.4.1` for package/archive metadata and `V0.4.1` for the Git tag and GitHub Release tag.
- Exclude `AGENTS.md` from all staging and commits.
- Do not force-push, retag, delete or replace any existing remote release asset.
- Do not publish V0.4.1 until all checks and its new Ubuntu archive succeed.

Run this PowerShell block after Step 3. It builds the wheel, installs it in a fresh virtual environment, imports the required modules, extracts the archive, then executes the same non-executable-helper regression path against the extracted scripts:

```powershell
$ErrorActionPreference = "Stop"
$repo = (Resolve-Path .).Path
$work = Join-Path ([System.IO.Path]::GetTempPath()) ("contentai-v041-verify-" + [guid]::NewGuid())
New-Item -ItemType Directory -Path $work -Force | Out-Null
try {
  & uv build
  if ($LASTEXITCODE -ne 0) { throw "uv build failed with exit code $LASTEXITCODE." }

  $wheel = Join-Path $repo "dist/contentai-0.4.1-py3-none-any.whl"
  if (-not (Test-Path -LiteralPath $wheel)) { throw "Expected wheel is missing: $wheel" }
  $venv = Join-Path $work "venv"
  & uv venv $venv
  if ($LASTEXITCODE -ne 0) { throw "uv venv failed with exit code $LASTEXITCODE." }
  $python = Join-Path $venv "Scripts/python.exe"
  & uv pip install --python $venv\Scripts\python.exe $wheel
  if ($LASTEXITCODE -ne 0) { throw "wheel installation failed with exit code $LASTEXITCODE." }
  & $python -c "import api.app; import agent.prompts.registry"
  if ($LASTEXITCODE -ne 0) { throw "wheel import probe failed with exit code $LASTEXITCODE." }

  $archive = Join-Path $repo "dist/contentai-0.4.1-ubuntu.tar.gz"
  if (-not (Test-Path -LiteralPath $archive)) { throw "Expected archive is missing: $archive" }
  $extract = Join-Path $work "extract"
  New-Item -ItemType Directory -Path $extract -Force | Out-Null
  & tar -xzf $archive -C $extract
  if ($LASTEXITCODE -ne 0) { throw "archive extraction failed with exit code $LASTEXITCODE." }
  $packageRoot = Join-Path $extract "contentai-0.4.1-ubuntu"
  $upgrade = Join-Path $packageRoot "infra/ubuntu/upgrade.sh"
  $backup = Join-Path $packageRoot "infra/ubuntu/backup.sh"
  $health = Join-Path $packageRoot "infra/ubuntu/health.sh"
  foreach ($path in @($upgrade, $backup, $health)) {
    if (-not (Test-Path -LiteralPath $path)) { throw "Extracted script is missing: $path" }
  }
  $packageRootBash = (& bash -lc "wslpath -u '$packageRoot'").Trim()
  if ($LASTEXITCODE -ne 0 -or [string]::IsNullOrWhiteSpace($packageRootBash)) {
    throw "Could not convert extracted package path for the Bash permission probe."
  }
  $probe = @'
set -euo pipefail
PACKAGE_ROOT="$1"
chmod 0644 "$PACKAGE_ROOT/infra/ubuntu/upgrade.sh" "$PACKAGE_ROOT/infra/ubuntu/backup.sh" "$PACKAGE_ROOT/infra/ubuntu/health.sh"
printf 'POSTGRES_DB=test\nPOSTGRES_USER=postgres\n' > "$PACKAGE_ROOT/.env"
FAKE_BIN="$(mktemp -d)"
cleanup() { rm -rf "$FAKE_BIN"; }
trap cleanup EXIT
printf '%s\n' '#!/usr/bin/env bash' 'exit 0' > "$FAKE_BIN/docker"
chmod 0755 "$FAKE_BIN/docker"
PATH="$FAKE_BIN:$PATH" bash "$PACKAGE_ROOT/infra/ubuntu/upgrade.sh"
BACKUP_FILE="$(find "$PACKAGE_ROOT/backups" -type f -name '*.sql.gz' -size +0c -print -quit)"
test -n "$BACKUP_FILE"
printf 'archived_permission_probe=PASS\n'
'@
  $probeBase64 = [Convert]::ToBase64String([Text.Encoding]::UTF8.GetBytes($probe))
  & bash -c "echo $probeBase64 | base64 -d | bash -s -- '$packageRootBash'"
  if ($LASTEXITCODE -ne 0) { throw "Archived 0644 permission probe failed with exit code $LASTEXITCODE." }
}
finally {
  Remove-Item -LiteralPath $work -Recurse -Force -ErrorAction SilentlyContinue
}
```

Expected: `uv build`, the wheel installation, and the import probe all exit 0; `archived_permission_probe=PASS` is printed; and the extracted mode-`0644` helper scripts complete without `Permission denied` while creating a non-empty backup file.
