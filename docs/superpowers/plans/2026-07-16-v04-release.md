# ContentAI V0.4 Release Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Publish the verified productionization baseline as GitHub Release `ContentAI V0.4` with a deployable Ubuntu archive.

**Architecture:** Keep the existing uppercase Git tag convention while using semantic package/archive versioning. Use an isolated Docker Compose PostgreSQL project exclusively for validation, then publish only the confirmed productionization files and generated `0.4.0` archive; leave the local `AGENTS.md` untracked.

**Tech Stack:** Git, GitHub CLI, Docker Compose v2, PostgreSQL 16, PowerShell, Python/pytest/Ruff/Vulture, Node.js/npm, uv.

## Global Constraints

- Git tag and GitHub Release tag must be exactly `V0.4`.
- Python package version and Ubuntu archive version must be exactly `0.4.0`.
- Exclude `AGENTS.md` from all staging and commits.
- Do not force-push or rewrite history.
- Do not create a release until all checks and the Ubuntu archive succeed.

- [x] **Step 2: Implement the isolated test-dependency command**

```powershell
$Action = $args[0]
$EnvFile = Join-Path $env:TEMP "contentai-test-deps.env"
$Compose = @("--env-file", $EnvFile, "-p", "contentai-test-deps", "-f", "compose.yaml", "-f", "compose.dev.yaml")

if ($Action -eq "up") {
  @'
POSTGRES_DB=contentai_test
POSTGRES_USER=postgres
POSTGRES_PASSWORD=postgres
POSTGRES_PORT=5432
REDIS_PORT=6379
WEB_PORT=5190
API_PORT=8010
CONTENTAI_DATABASE__URL=postgresql+psycopg://postgres:postgres@postgres:5432/contentai_test
'@ | Set-Content -Encoding utf8 $EnvFile
  docker compose @Compose up --detach --wait postgres
  if ($LASTEXITCODE -ne 0) { throw "Unable to start isolated test PostgreSQL." }
} elseif ($Action -eq "down") {
  docker compose @Compose down --volumes --remove-orphans
  if ($LASTEXITCODE -ne 0) { throw "Unable to remove isolated test PostgreSQL." }
  Remove-Item -Force -ErrorAction SilentlyContinue $EnvFile
} else {
  throw "Usage: tools/test-deps.ps1 up|down"
}
```
