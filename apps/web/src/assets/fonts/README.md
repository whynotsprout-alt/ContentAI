# Self-hosted UI fonts

- `inter-latin-variable.woff2`: Inter Latin variable font, weights 300-600.
- `instrument-serif-latin.woff2`: Instrument Serif Regular, Latin subset.
- `instrument-serif-italic-latin.woff2`: Instrument Serif Italic, Latin subset.

The files are sourced from the Google Fonts distributions for Inter and
Instrument Serif. Both families are distributed under the SIL Open Font
License 1.1. Chinese glyphs intentionally use the system CJK fallback stack to
avoid shipping a multi-megabyte webfont.
